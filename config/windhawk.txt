Windhawk config

First setup:
This mod needs to hook into dwm.exe to work. Please navigate to Windhawk's Settings > Advanced settings > More advanced settings > Process inclusion list, and make sure that dwm.exe is in the list.

Second setup:
Download **Custom Window Corner Radius, macOS magnifying cursor, Dynamic Island for Windows**
And turn it on

Third setup
put all the config, turn the textual mode and copy & paste all code on below
